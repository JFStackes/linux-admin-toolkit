# `user create`

Creates a local Linux user with optional expiration, group membership, password authentication and SSH-key authentication.

## Usage

```bash
sudo jfstack-admin user create USERNAME [OPTIONS]
```

## Options

- `--expires none|24h|1d|7d|1m|1y|YYYY-MM-DD`
- `--sudo`
- `--docker`
- `--generate-password`
- `--password VALUE` (discouraged because command-line secrets can leak through shell history/process inspection)
- `--public-key VALUE`
- `--public-key-file PATH`
- `--generate-ssh-key`
- `--key-output-dir PATH`
- `--shell PATH`

## Security notes

Docker group membership can effectively grant root-equivalent control on common Docker installations. Private keys generated by the toolkit are not written to logs and are created with restrictive permissions.
