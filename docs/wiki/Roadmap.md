# Roadmap

## v0.1

- Core menu and CLI dispatcher.
- User lifecycle basics.
- Password and SSH-key authentication provisioning.
- Read-only administration and diagnostic modules.
- Diagnostic report generation.
- Initial GitHub Wiki.

## v0.2

- Richer service management.
- Storage analysis and large-file discovery.
- Improved network diagnostics.
- Expanded logs and systemd workflows.
- Safer non-interactive flags and exit-code documentation.

## v0.3

- Docker/Compose operations.
- Firewall operations with explicit backend detection.
- Certificate inventory and expiry checks.
- Package/security update workflows.

## v1.0 target

- Stable CLI contract.
- Tested Debian/Ubuntu and RHEL-family support.
- Automated CI with ShellCheck and integration tests.
- Complete Wiki command reference.
